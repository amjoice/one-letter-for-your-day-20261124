One letter for the day: **X** — for *exhausted*. Not the obvious pick (E would be) but the sharper one: the sound of "ex-", the mark of a day crossed off, an honest report of a day spent entirely. Vivid, funny, and true — the kind of word a reader repeats to a friend.

The program writes exactly one character, `X`, to `/output/entry.txt` — no word, no gloss, no punctuation, no trailing newline — and validates it first (one ASCII letter, A–Z) so a bad entry can never ship.

## Run it

```sh
python3 main.py
```
